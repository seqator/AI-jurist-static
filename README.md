# AI Jurist Demo

Статическая демо-версия консультанта по банкротству.

- Работает целиком в браузере.
- База знаний и правила диалога встроены в страницу.
- Заявка сохраняется в `localStorage`, никуда не отправляется.
- Голосовой ввод в демо-версии отключён.
- Озвучка ответов идёт голосом браузера.
- Полная версия с Vosk, Python-сервером и сохранением заявок лежит в GitHub.

Это демонстрация интерфейса и сценария, а не публичная юридическая консультация.
